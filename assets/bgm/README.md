# Diretório de Trilhas Sonoras (BGM)

Este diretório contém os arquivos de áudio que serão usados como trilha sonora (Background Music - BGM) nos vídeos gerados pelo sistema DarkAI.

## Formatos Suportados
- `.mp3`
- `.wav`
- `.m4a`

## Requisitos das Trilhas
1. **Royalty-Free**: Certifique-se de que todas as trilhas contidas neste diretório são livres de direitos autorais ou você tem a licença para utilizá-las no YouTube/TikTok.
2. **Nomeação**: O nome do arquivo será usado como "ID" e "Nome" da trilha pela IA para realizar a seleção automática baseada no tema do vídeo.
   - Exemplo: `suspense_cinematografico.mp3` será identificado como "Suspense Cinematografico".
   - Tente utilizar nomes descritivos (ex: `lofi_relaxante.mp3`, `terror_sombrio.wav`).

## Utilização
O sistema listará automaticamente todos os arquivos válidos neste diretório, identificará sua duração e permitirá que a IA selecione a melhor opção com base no nicho e tema do vídeo, mixando de forma suave com a narração principal.
